## Shipped behavior

- Studio uses a full `WorkspaceHeader` with explicit project context, native
  instrument controls/canvas, concise first-chord-or-exact summary and exact
  octave note labels, **Save idea**, **Add to Writer**, **Scale** and **Idea
  library**. These reuse the existing save/key/recognized-versus-exact flows.
- One inline Notes / Voicings / Setup inspector defaults to Voicings and can
  collapse/reopen. Offstage retains a single native picker and setup instance;
  there is no additional hidden chord-sheet picker. Selecting a detection
  result opens the inline Voicings tab. Native root, quality, octave and
  committed-voicing state survive tab/collapse changes.
- Split layout requires >=700px width and >=500px available height. Its
  inspector column is 316px, or 360px from 1000px up, including outer margins.
  Each side scrolls independently. Compact/short windows use a scrolling page.
  Fretboard's 328px and Piano's 244px native host heights remain fixed; neither
  musical geometry nor gesture/hit/scroll math was resized or replaced.
- Guitar keeps Free/Chord, readable tuning/capo and explicit Free-ineligible
  Writer explanation. Setup includes Exact/Solo, existing categorized tuning
  selector and a 44px capo stepper/fret row that scrolls rather than wrapping
  CAPO into a tiny column. Tuning context shares the existing spelled tuning
  formatter, including Eb/D# Standard.
- Piano keeps 49/61/88 ranges, Exact/Solo, octave/inversions and exact-MIDI
  audition/scroll. Octave/range controls have 44px targets. The voicing carousel
  grows with text scale while its actual miniature keyboard remains unchanged.
- All owned semantic instrument colors resolve `StudioPalette` locally. Native
  fretboard, guitar diagram and Piano diagram painters accept immutable palette
  values and include them in `shouldRepaint`; Piano's actual key widgets also
  resolve live palette. No mutable theme singleton or new provider/container.
- Every direct instrument/handoff/name/key-conflict route in owned files now
  uses `showStudioDialog` / `showStudioModalBottomSheet`. Open name-dialog state
  survives changing the root Studio variant. Shared root route behavior remains
  foundation-owned.
- Main passes existing native Save panels with linked-edit save ID,
  different-save callback and handoff completion callback intact. Inline setup
  uses explicit `closeAfterClear:false`; legacy sheet behavior remains available.
- Unthemed/legacy InstrumentScreen hosts keep the previous dock composition.
  Their geometry/gesture regression suite continues to pass.
