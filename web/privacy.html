Muzician

Privacy

Last updated: 8 November 2026

The short version. Your projects, lyrics, saves and audio stay on your device. There is no account, no cloud sync and no analytics. The only thing that ever leaves is a feedback message you choose to send from Settings.

Feedback you choose to send

Muzician has exactly one outbound write: the in-app feedback form at Settings → Send feedback, available on web and Android. Nothing is sent unless you write a message and press Send.

Only the message you write, an optional email address, and these details are sent: app version, platform, operating system, screen and language. Your projects, lyrics and saves never leave your device. There is no analytics, no tracking and no account. Feedback is kept until it is deleted — email bytebakehouseinc@gmail.com to have it removed.

What a submission contains

Field What it is
Message The text you type, up to 4000 characters.
Category One of bug, idea, confusing or other, so the report can be triaged.
Email address Optional. Only sent if you type one, so you can receive a reply.
App version For example 2.0.0+2, to reproduce a bug on the right build.
Platform and OS Web or Android, plus a coarse operating-system description such as “Chrome / macOS” or “Android 14”.
Screen and language Where in the app the form was opened (Settings) and the device language code.
Created at A server timestamp added when the submission is stored.
Client session id A random value regenerated each time the app launches, used only to spot repeated sends. It is not a device identifier and is not kept between launches.

What never leaves your device

  • Projects, project names, keys and chord selections
  • Writer sections, patterns, notes and lyrics
  • Save System entries, versions and folders
  • Audio recordings, samples and exported files
  • Anything you have not typed into the feedback form

No account is created, no profile is built, and Muzician does not collect advertising identifiers, location, contacts or usage analytics.

Why it is collected

Feedback is used to find and fix bugs, understand what is confusing and decide what to build next. If you leave an email address, it is used only to reply about your feedback.

How long it is kept

Feedback is kept until it is deleted. You can ask for a submission to be removed at any time by emailing bytebakehouseinc@gmail.com; the matching document is deleted from the developer's database and you receive a confirmation. There is no other retention or deletion schedule.

Who can read it

Submissions go to a private Firebase Cloud Firestore collection owned by the developer. The app can create a submission but cannot read, update or delete one, and no other user can read the collection. Data is encrypted in transit over HTTPS. It is not sold, rented or shared with third parties; Google provides the storage as a data processor. The hosting and database providers log request metadata such as the source IP address.

Analytics and tracking

Muzician does not use an analytics, crash-reporting or advertising SDK, and sends no analytics events, screen views or session recordings. The app's Firebase configuration contains a Google Analytics measurement id generated by the Firebase tooling, but no analytics package is included and nothing reports to it.

Contact

Questions about this policy or a deletion request: bytebakehouseinc@gmail.com.
